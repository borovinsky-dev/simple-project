# Учебный проект по FastAPI

Этот репозиторий создан для обучения по курсу FastAPI. Здесь я изучаю создание API, обработку запросов, валидацию данных с помощью Pydantic и организацию проекта по модулям.

## Требования

- Python 3.14 или новее
- [uv](https://docs.astral.sh/uv/)

## Установка зависимостей

Из корневой папки проекта выполните:

```powershell
uv sync
```

## Запуск сервера разработки

```powershell
uv run uvicorn simple_project.main:app --reload
```

После запуска API будет доступно по адресу <http://127.0.0.1:8000>, интерактивная документация — по адресу <http://127.0.0.1:8000/docs>.
